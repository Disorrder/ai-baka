# ADR-0006: Не угадывать источник при неоднозначном переименовании

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Несколько исчезнувших источников с одинаковым содержимым не определяют единственного предшественника нового файла.

## Решение

При неоднозначном переименовании считать новый источник независимым, а не выбирать произвольный прежний.

## Последствия

Возможна отдельная сущность для копии, зато не искажается происхождение данных.
