# ADR-0018: Стоимость оценивается по явно заданному тарифу

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Тариф внешнего сервиса может измениться независимо от приложения.

## Решение

Оценивать стоимость по явно заданному тарифу, не по постоянной цене, зафиксированной разработчиком.

## Последствия

Оценка отражает выбранный тариф, а не скрытое предположение о цене.
