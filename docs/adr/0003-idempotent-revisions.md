# ADR-0003: Повторная обработка не дублирует ревизии

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Повторный запуск должен быть идемпотентным, а содержательные изменения — различимыми.

## Решение

Одинаковые данные одного диалога при тех же правилах разбора дают ту же ревизию. Изменение правил, содержимого, metadata или исходного usage должно учитываться при определении ревизии.

## Последствия

Совпадения текста недостаточно, чтобы считать ревизии одинаковыми; повтор без изменений не создаёт новую историю.
