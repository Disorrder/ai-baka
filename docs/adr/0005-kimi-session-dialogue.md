# ADR-0005: Диалог Kimi — целая сессия

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Одна сессия Kimi распределена по нескольким исходным файлам; их части не являются независимыми диалогами.

## Решение

Обрабатывать сессию как единый диалог. Если не удалось сохранить любой её файл, не пересобирать и не переключать диалог на неполную версию. Индекс сессий сохраняется как источник, но не трактуется как диалог.

## Последствия

Успешная обработка отдельного файла не разрешает обновление всей сессии.
