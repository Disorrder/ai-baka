# ADR-0020: Резервная копия описывает исходное состояние

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Изменение рабочего архива не меняет содержимое ранее созданной копии.

## Решение

Не переписывать метаданные сохранённой копии так, будто она создана из нового состояния архива.

## Последствия

Старая копия остаётся свидетельством исходного состояния; обновлённый архив требует собственной копии.
