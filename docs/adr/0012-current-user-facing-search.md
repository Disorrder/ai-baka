# ADR-0012: Поиск по актуальным вопросам и финальным ответам

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Пользователь ищет свои вопросы и полученные ответы, а не служебные события и всю физическую историю.

## Решение

Искать отдельные пользовательские вопросы и финальные видимые ответы только текущих ревизий диалогов. Исторические и служебные данные сохраняются отдельно, но не включаются в эту выдачу.

## Последствия

Поиск отражает актуальное состояние диалога; его состав отличается от полного сохранённого архива.
