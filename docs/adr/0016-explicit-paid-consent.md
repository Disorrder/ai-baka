# ADR-0016: Платная обработка требует отдельного согласия

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Наличие ожидающих документов не даёт разрешения на расходы или отправку данных.

## Решение

Запускать платные оценочные и полные обработки только с предусмотренными подтверждениями и лимитами. Не обходить согласование альтернативным способом запуска.

## Последствия

План и очередь сами по себе не разрешают платную операцию.
