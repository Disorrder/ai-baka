# ADR-0013: Одно сообщение не дублируется в выдаче

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Разные способы поиска могут найти одно и то же сообщение.

## Решение

Объединять совпадения по сообщению до ограничения числа результатов.

## Последствия

Одно сообщение не занимает несколько мест за счёт нескольких способов обнаружения.
