# ADR-0002: Пробный запуск не меняет архив

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Пользователь должен оценить предстоящую синхронизацию до её применения.

## Решение

Пробный запуск рассчитывает действия, но не изменяет сохранённые данные и исходные снимки.

## Последствия

Предварительная проверка безопасна для корпуса, но не доказывает успех будущего полного запуска.
