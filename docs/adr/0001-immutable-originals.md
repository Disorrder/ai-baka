# ADR-0001: Исходные данные сохраняются неизменными

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Повторный разбор должен опираться на исходное содержимое, даже если источник изменён или удалён.

## Решение

Сохранять неизменяемые снимки исходных данных. Путь и время изменения не заменяют идентичность содержимого.

## Последствия

История доступна для повторной обработки; удаление источника не разрешает удалять снимок.
