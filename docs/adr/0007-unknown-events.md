# ADR-0007: Не терять неизвестные события

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Неизвестное сегодня событие может стать понятным после обновления правил разбора.

## Решение

Сохранять неизвестные события полностью, без усечения содержимого.

## Последствия

Новые правила смогут использовать ранее непонятные поля; размер события не оправдывает молчаливую потерю данных.
