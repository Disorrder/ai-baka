# ADR-0022: Отсутствие ссылок не разрешает удаление исходника

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Исходный файл без ссылок может требовать расследования, но не обязательно является ненужным.

## Решение

Проверка исходных данных ничего не меняет. Файл без ссылок — предупреждение, не ошибка сохранности и не разрешение на удаление.

## Последствия

Решение об удалении нельзя вывести только из отсутствия ссылок.
