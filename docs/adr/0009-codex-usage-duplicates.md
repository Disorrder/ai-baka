# ADR-0009: Повторы лимитов Codex не умножают usage

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Codex повторяет одинаковую информацию о расходе для соседних групп лимитов.

## Решение

Последовательные копии одного token_count.info между группами лимитов не считать новыми расходами.

## Последствия

Итог отражает реальные вызовы, а не число групп лимитов.
