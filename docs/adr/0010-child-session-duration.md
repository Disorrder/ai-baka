# ADR-0010: Время родителя не является временем дочерней сессии

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Воспроизведённая история родителя содержит уже завершённые ходы, не исполненные дочерней сессией.

## Решение

Не добавлять длительность унаследованных завершённых ходов к длительности дочерней сессии; учитывать время исходного хода, а не момент копирования истории.

## Последствия

Длительность дочерней сессии не растёт из-за унаследованного контекста.
