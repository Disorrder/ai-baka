# ADR-0011: Повторный разбор закрывает прежние ошибки

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Старые ошибки не должны навсегда оставаться текущими после новой обработки.

## Решение

При повторном разборе ревизии закрывать её прежние неразрешённые ошибки обработки.

## Последствия

История ошибок сохраняется, но актуальная диагностика не включает уже обработанные старые ошибки.
