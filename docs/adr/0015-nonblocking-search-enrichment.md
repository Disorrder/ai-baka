# ADR-0015: Обогащение поиска не блокирует архивирование

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Доступность внешнего поиска и расходы на него не должны определять возможность сохранить диалог.

## Решение

Сохранять диалоги независимо от вычисления их векторных представлений; обогащение поиска выполнять отдельно.

## Последствия

Архив может быть сохранён раньше, чем готов семантический поиск.
