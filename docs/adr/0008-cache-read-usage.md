# ADR-0008: Cached input означает только чтение кеша

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Создание кеша и чтение из него — разные виды расхода.

## Решение

Учитывать в cached input tokens только cache read; cache creation сохранять отдельно в исходном usage.

## Последствия

Нормализованный счётчик сопоставим между харнессами без потери детализации.
