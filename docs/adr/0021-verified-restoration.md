# ADR-0021: Восстановление подтверждается целостностью данных

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Успешная загрузка и совпадение количества записей не доказывают сохранность архива.

## Решение

До восстановления подтвердить подлинность и полноту копии. Принимать результат после проверки количества сущностей, целостности связей, соответствия исходным данным и работоспособности поиска.

## Последствия

Одна проверка количества записей не даёт оснований считать восстановление успешным.
