# ADR-0014: Не более трёх совпадений на диалог

**Статус:** Принято · **Дата фиксации:** 2026-09-09

## Контекст

Один длинный диалог не должен вытеснять остальные из результатов.

## Решение

После устранения повторов сообщений оставлять не более трёх совпадений на диалог, затем применять общий лимит выдачи.

## Последствия

Пользователь видит больше разных диалогов; порядок ограничения влияет на состав результата.
